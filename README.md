# EEBox - An open-source simple sandbox game built on Unity 2022.3.62f3. 
What does EEBox mean? Extremely Easy Box. 
This game has no dumb things like built-in save or mod systems, tools or complicated things. Only dragging, creation and activation.

Available Platforms: PC (Windows/Linux) and Web.

## Dependencies & Requirements for Publishing
Engine: Unity 2022.3.62f3
